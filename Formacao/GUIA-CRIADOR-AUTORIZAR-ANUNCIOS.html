Autorizar Anúncios

Siga este guia para ativar a monetização de anúncios nos seus vídeos TikTok. Cada vídeo precisa de autorização individual para receber anúncios.

⚠️ Importante

Para ativar a monetização com anúncios nos seus vídeos, é necessário autorizar os anúncios EM CADA VÍDEO. Ter a autorização ativada nas configurações gerais não é suficiente!

Fluxo de Autorização

🎯 1º ACESSO - Primeira Autorização

Passo 1: Acesse Configurações de Anúncios

Abra o menu do seu vídeo (3 pontos), arraste para o lado e clique em "Configuração de anúncios". Você verá a tela com todos os toggles disponíveis para monetizar seu conteúdo.

📱 Tela de configuração de anúncios

Passo 2: Ative "Autorização de Anúncio" e "Autorização de Âncora"

Ative os dois toggles principais: "Autorização de anúncio" (para exibição de anúncios) e "Autorização de âncora" (para links de marcas). Ambos devem ficar azuis/ativos.

📸 Menu de compartilhamento com opções

Passo 3: Confirme "A autorização dura 365 dias" e Clique em SALVAR

Deixe a duração em "A autorização dura 365 dias" e clique no botão vermelho SALVAR para confirmar todas as configurações iniciais.

✓ Clique em "Salvar"

✓ 1ª Autorização Concluída!

🔄 2º ACESSO - Gerar Spark Code

Após salvar a autorização inicial, volte ao mesmo vídeo e repita os passos 1 e 2. Então siga para gerar o código:

Passo 1 e 2: Repita os Passos Anteriores

Abra novamente a "Configuração de anúncios" e verifique se os toggles já estão ativados (estarão azuis).

Passo 3: Gere o Spark Code

Na seção "Código do vídeo", clique em "Gerenciar" para acessar as opções de geração do Spark Code.

🎯 Clique em "Gerenciar" para gerar código

Passo 4: Copiar e Enviar o Código

  1. Gerar Código (Spark Code): Defina o tempo de autorização (ex: 30, 60 dias) e clique em "Gerar" ou "Gerar Código".
  2. Copiar e Enviar: Clique em "Copiar código". Esse código pode ser enviado diretamente para a marca no TikTok Ads Manager ou por mensagens.

✓ Spark Code Gerado e Copiado!

Tutoriais Adicionais

📌 Autorizar Vídeos de Afiliados para Shop Ads

Pela Central de Criador

  1. Acesse o TikTok Shop Creator Center no app TikTok
  2. Toque no menu do canto superior direito
  3. Acesse Configurações e toque em Configurações de privacidade
  4. Toque no botão para ativar a opção Autorizar vendedores a impulsionar meus vídeos
  5. Você pode desativar essa opção a qualquer momento

📌 Como Funciona a Monetização

Pontos Importantes

  1. 2 acessos necessários: 1º para autorizar, 2º para gerar código
  2. Autorização por vídeo: Cada vídeo precisa de sua própria ativação
  3. 365 dias: A monetização é válida por um ano completo
  4. Spark Code: Código rápido para compartilhar com marcas
  5. Toggles ativos: Anúncios + Âncora devem estar azuis
⚠️

Importante!

São DOIS acessos diferentes: Primeiro você autoriza e salva. Depois você volta no mesmo vídeo para gerar e copiar o Spark Code. Não tente fazer tudo de uma vez!

💡

Dica

Após salvar a primeira autorização, aguarde alguns minutos para o TikTok processar. Os toggles devem ficar azuis quando ativados. No segundo acesso, você terá acesso a "Gerenciar" para copiar o Spark Code!

📌 Próximo Passo

Após gerar o Spark Code, envie-o via WhatsApp para seu gestor: "✅ Autorização ativada! Spark Code: [INSIRA]"

Resumo Rápido

  • 1º Acesso: Abra Configuração → Ative toggles → Confirme 365 dias → Clique em "Salvar"
  • 2º Acesso: Abra Configuração → Acesse "Código do vídeo" → Clique em "Gerenciar" → Gere código → Copie
  • Envie o Spark Code via WhatsApp ✅
